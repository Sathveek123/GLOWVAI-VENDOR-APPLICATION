## 🎯 Screen Purpose & Behavior
Collects bank account details and UPI ID for daily/weekly payout settlements (88% vendor net payout).

---

## 🎨 Form Fields
1. **Account Holder Name**: e.g., *"Mukesh Kumar"*.
2. **Bank Name**: Dropdown / Input (e.g. *HDFC Bank*).
3. **Account Number & Confirm Account Number**.
4. **IFSC Code**: e.g. `HDFC0001824`.
5. **VPA / UPI ID**: e.g. `mukesh.kumar@okhdfcbank`.
