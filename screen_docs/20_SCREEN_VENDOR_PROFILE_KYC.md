# 📱 Screen Documentation: Store Profile & Bank Account Edit Screens

## 📍 File & Component Location
- **Profile Screen**: `mobile/app/(vendor)/profile.tsx` (`/(vendor)/profile`)
- **Bank Edit Screen**: `mobile/app/(vendor)/bank-edit.tsx` (`/(vendor)/bank-edit`)

---

## 🎯 Purpose & Behavior

### Profile Screen (`profile.tsx`)
- Displays dark store profile details, shop address, rating (`4.96 ⭐`), KYC verification badge (`APPROVED`), GSTIN, PAN, operating hours, and active categories.
- Includes a *"Logout & Clear Session"* button.

### Bank Edit Screen (`bank-edit.tsx`)
- Allows vendor to update bank account number, IFSC code, or UPI ID for direct payout settlements.
- Requires re-authentication OTP for security.
